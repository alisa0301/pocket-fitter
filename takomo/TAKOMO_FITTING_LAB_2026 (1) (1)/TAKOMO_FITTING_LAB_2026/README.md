# Takomo Fitting Lab · Since AI Hackathon 2026

Synthetic golfers, today's fitting rules as code, a calibrated ball-flight model, a scorer and a phone-camera kit for Takomo Golf's challenge **The Fitter in Your Pocket**.

Start with **START_HERE.html** (or START_HERE.md).

```bash
pip install numpy pandas
python examples/quickstart.py
```
